# Student Toolkit release roadmap

## V1.0 — first Galaxy Store release
Offline-first; no account, internet connection, Firebase, or cloud sync required. Approved scope: Dashboard, Subjects and tags, Homework, Notes, Timetable, Exam Countdown, Focus Timer (Pomodoro/stopwatch/countdown with verified local sessions), Progress Analytics/Study Score, Settings and Privacy. Release requires the measurable gates in [V1 quality benchmarks](docs/v1-quality-benchmarks.md), automated verification, integration testing and physical Android install/upgrade/use testing. Do not claim Settings/Privacy verified until the GitHub emulator workflow passes.

## V1.1 — separately approved expansion, not implemented
Student Templates (3 free plus optional paid education templates), Student Essentials affiliate links, offline ML Kit Smart Syllabus Scanner with user review before import, and manual .ICS Calendar Export. Firebase is excluded. Optional login/cloud sync provider is undecided and must not be assumed or implemented without separate approval. Preserve offline/guest core operation. Estimates must be reviewed feature by feature; scanner preliminary estimate +8–14 days and manual calendar export +2–3 days.

## V2.0 — future scope
Advanced features require separate requirements, estimates and owner approval. V1.1/V2.0 must not delay V1.0 readiness.

No release or main-branch merge without owner approval.
